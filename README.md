# Avito Parser

Расширение Chrome (Manifest V3) для умного сбора объявлений с Avito, анализа цен и экспорта результатов в Markdown, JSON и TSV.

## Возможности

- **Мгновенный парсинг**: сбор данных со страниц поиска (через `__NEXT_DATA__` + DOM fallback);
- **Авто-отслеживание поиска**: обнаружение изменения поисковой фразы/фильтров на странице с кнопкой мгновенного пересбора;
- **Аналитика цен в реальном времени**: автоматический расчёт минимальной, средней и максимальной цены с выделением бейджа **«★ Лучшая цена»**;
- **Пагинация**: последовательная подгрузка следующей страницы или всех страниц каталога;
- **Фильтрация и поиск**: фильтрация по наличию доставки, исключение резерва, поиск по номеру лота, плюс/минус слова;
- **Компактный режим**: сворачивание панели фильтров в один клик для максимизации рабочей зоны;
- **Быстрые действия**: копирование ссылки конкретного лота в 1 клик, копирование всей выборки в Markdown/JSON/TSV;
- **Интерактивный UI**: плавная анимация появления карточек (stagger), hover-zoom фото, skeleton-загрузка и всплывающие тост-уведомления;
- **Горячие клавиши**: <kbd>Alt + P</kbd> для вызова панели, <kbd>Escape</kbd> для закрытия;
- **Адаптивный дизайн**: поддержка светлой и тёмной темы.

## Установка

1. Скачайте репозиторий:

   ```bash
   git clone https://github.com/TopMob/avito_tool.git
   ```

2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите каталог репозитория.

## Использование

1. Откройте любую страницу поиска на [avito.ru](https://www.avito.ru).
2. Нажмите плавающую кнопку в правом нижнем углу или комбинацию <kbd>Alt + P</kbd>.
3. Выберите нужные фильтры, поля и формат экспорта.

## Структура

```text
background/   фоновый сервис-воркер
content/      интерфейс панели (Shadow DOM), стили и логика отслеживания
popup/        окно расширения в панели браузера
shared/       модуль парсинга данных и форматирования экспорта
manifest.json манифест Manifest V3
```
