# Avito Parser

Расширение Chrome (Manifest V3) для сбора объявлений с Avito и экспорта результатов в Markdown, JSON и TSV.

## Возможности

- сбор данных со страниц поиска;
- загрузка нескольких страниц выдачи;
- фильтрация по ключевым словам, доставке и резерву;
- настройка набора полей;
- экспорт в Markdown, JSON и TSV;
- светлая и тёмная тема.

## Установка

1. Скачайте репозиторий:

   ```bash
   git clone https://github.com/TopMob/avito_tool.git
   ```

2. Откройте `chrome://extensions/`.
3. Включите режим разработчика.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите каталог репозитория.

## Использование

Откройте страницу поиска на [avito.ru](https://www.avito.ru), запустите расширение и выберите нужные поля, фильтры и формат экспорта.

## Структура

```text
background/   сервис-воркер
content/      интерфейс и логика на странице
popup/        окно расширения
shared/       общий парсер
manifest.json манифест Manifest V3
```

Расширение использует DOM и внутренние данные страницы Avito, поэтому изменения сайта могут потребовать обновления парсера.
