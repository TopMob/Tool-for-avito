# Tool for Avito

Кроссбраузерное расширение (Manifest V3) для Firefox и Chromium-браузеров для содействия пользователю в аналитике цен и структурированном экспорте общедоступных объявлений с сайта avito.ru в форматы Markdown, JSON и TSV для персонального анализа.

---

## Возможности

- **Мгновенный экспорт текущей страницы**: извлечение данных из открытой вкладки поиска через структурированные данные страницы (`__NEXT_DATA__` + DOM fallback);
- **Аналитика цен в реальном времени**: автоматический расчёт минимальной, средней и максимальной цены с отметкой лучшего предложения;
- **Интеллектуальная фильтрация**: фильтр по наличию доставки, исключение резерва, поиск по номеру лота, плюс/минус-слова через запятую;
- **Экспорт в 1 клик**: копирование выборки в буфер обмена (Markdown для диалога с ИИ, чистый JSON, TSV для Excel/Google Таблиц);
- **Изолированный интерфейс**: панель управления в закрытом **Shadow DOM** без влияния на исходную вёрстку страницы;
- **100% локальная работа (Zero Telemetry)**: расширение не использует сторонние серверы, прокси или трекеры аналитики. Все данные обрабатываются исключительно в браузере пользователя;
- **Удобное управление**: плавающая кнопка (FAB) в правом нижнем углу и окно в панели инструментов (Popup), <kbd>Escape</kbd> для закрытия панели;
- **Сохранение сессий**: автоматическое сохранение до 300 лотов последнего поиска в `chrome.storage.local` с возможностью быстрого экспорта (Markdown, JSON, TSV) прямо из попапа без повторного захода на Авито.

## Установка

### Firefox
* **Из каталога дополнений Mozilla (AMO):** установите со страницы расширения в [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tool-for-avito/) *(после публикации)*.
* **Временная установка для разработки:**
  1. Откройте страницу `about:debugging#/runtime/this-firefox`.
  2. Нажмите **Загрузить временное дополнение...** (Load Temporary Add-on).
  3. Выберите файл `manifest.json` в папке проекта.

### Chromium-браузеры (Chrome, Edge, Brave, Яндекс.Браузер)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/TopMob/Tool-for-avito.git
   ```
2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked).
5. Выберите папку репозитория.

## Использование

1. Откройте любую страницу поиска на сайте [avito.ru](https://www.avito.ru).
2. Нажмите плавающую кнопку в правом нижнем углу или кнопку «Собрать объявления» в окне расширения в тулбаре.
3. Выберите нужные фильтры, поля и формат экспорта.
